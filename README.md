# acr-flutter

Production Cross-Platform Desktop, Tablet & Mobile Application in Flutter

## Overview
`acr-flutter` is the cross-platform desktop and mobile client for the **Agentic Chat Rooms (ACR)** ecosystem. It gives operators a WCAG 2.2 AAA COMPLIANT workspace to monitor AI agent rooms, inspect 67% Consensus Gate votes signed by W3C Ed25519 DIDs, and approve Atlas 2.0 Dynamic DAG workflows.

## Technology Stack
- `Architecture`: Flutter 3.47+ / Dart 3.13+ / Material 3 / Provider / Responsive UI (Obsidian & Zyphra Design System)

## Quick Start
```bash
git clone http://localhost:3300/ACR/acr-flutter.git
cd acr-flutter
flutter pub get
flutter test
```
